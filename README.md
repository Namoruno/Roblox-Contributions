# Roblox-Contributions

## Anti Cheat

### Bandaid
Bandaid anticheat is a couple hundred lines of protection that provide a one stop shop for remote events and speed hacks.  
Though it is not a full-proof anticheat, it strongly disrupts the cheat experience until your game is mainstream.

### EcoEquity
EcoEquity is a simple anticheat that monitors a player's datastores for inconsistencies.  
It is not a full-proof anticheat alone, but pairs well with Bandaid when finding sub level 6 exploits.
